STAFF PLATFORM ENGINEER, AGENTIC ENGINEERING

Developer Productivity · AI Coding Agents · Developer Platform

Our ambition: an engineering organisation where humans and agents work as one continuously learning system, turning frontier AI capabilities and real-world feedback into more ambitious product development. We want n8n to be the reference for how this is done, without compromising quality, resilience or trust. Your main goal is to make that real.



This is a Staff individual contributor role in Developer Platform and the technical driving force behind ACDC (Agent-centric Development Cycle), our engineering-wide initiative for agentic development. Nobody has a playbook for this yet. You'll write ours.



You won't start from zero. Agents wired into Linear already automate around 80% of the development cycle on one of our developer platform projects, alongside pilots for insight, feature-flag and PR-review agents and a shared agent harness. Your job is to take this from promising experiments to the way n8n builds software.



This role is for someone who thinks about this problem constantly. You run agents all day, rebuild your own workflow every time the frontier moves, and have more ideas than time. 



You'll stay hands-on, building the first versions yourself, and shape how the work grows beyond one person.




WHAT YOU'LL DO


SET DIRECTION AND OWN THE OUTCOME

 - Identify where agentic development can make the greatest difference, using developer feedback, existing experiments and engineering performance data.

 - Set the strategy and priorities across agent execution, repository readiness, CI, security and developer workflows.

 - Make build, buy or pass decisions on tools and vendors, and own the cost and value trade-offs, including AI spend.

 - Make decisions where requirements are incomplete and the trade-offs between autonomy, reliability, security and review effort are still emerging.

 - Build alignment through technical proposals, clear decisions and working software, and report progress and impact to engineering leadership.


BUILD THE FOUNDATIONS

 - Design and build isolated execution environments where agents can work with the right access to code, tools and context, without exposing secrets or sensitive systems.

 - Own the safety model: which task categories agents may attempt, what they must never touch, and where human review is required, partnering with Security on sensitive areas like auth, billing, permissions and data handling.

 - Make n8n's monorepo agent-ready, working with Architecture and senior engineers on repo structure, testability, boundaries and the context agents need.


INTEGRATE AGENTS INTO HOW WE WORK

 - Build repeatable workflows that take Linear issues through agent execution, self-verification and review to merged PRs, across a growing range of task types.

 - Integrate agentic workflows with GitHub, CI, test infrastructure and code review, so the agentic path becomes the easiest path for engineers.

 - Extend the loop beyond coding: connect earlier signals like product research and customer requests, and later ones like production metrics, so agents contribute across the whole cycle.

 - Open it up beyond engineering, so PMs, designers and others can turn a well-defined issue into a reviewed, mergeable change.

 - Shape review practices, such as PR evidence that shows what changed, what ran, what risks remain and where human judgment is needed.


MEASURE WHAT WORKS

 - Build benchmarks from real historical engineering tasks to evaluate output quality, failure modes, review burden and production risk.

 - Define and track quality and adoption signals, such as reviewer acceptance rate, CI pass rate, rework rate and developer satisfaction.

 - Use data and feedback to change course, retire what doesn't work, and build trust across engineering.


REQUIREMENTS


MUST-HAVES

 - 🔥 Frontier obsession: You live at the frontier. You try new models and tools as they land, and you have strong, evidence-backed opinions on what's real and what's hype.

 - 🧭 Staff-scope ownership: You’ve led complex platform, DevEx or engineering productivity initiatives across teams, from defining the problem to sustained adoption and measurable impact, where there was no established approach to follow.

 - 🤖 Agentic depth: You use coding agents daily as a power user, and you've built infrastructure around them, such as repo context and instructions, tool or MCP integrations, sandboxed execution or agent workflows in CI, that other engineers rely on.

 - 🎯 Product mindset for internal platforms: You treat engineers as your customers. You start from real friction, prioritise by impact, make build-vs-buy calls, weigh cost against value, and let adoption tell you whether something works.

 - 🤝 Direction without authority: You've set technical direction that multiple teams followed, through proposals, design reviews and credibility with senior engineers across Platform, Product Engineering, AI, Security and Architecture.

 - 🔐 Safety judgment: You've made real decisions on permissions, secrets, sandboxing, sensitive code paths and human-in-the-loop review, and can explain the trade-offs.

 - 📊 Measurement that drives decisions: You've built evaluations, benchmarks or quality metrics and used them to change course or retire things that didn't work. You care about outcomes, not lines of AI-generated code.

 - ✍️ Writing that changes decisions: Your technical proposals and documentation have shifted what teams did.


NICE-TO-HAVES

 - 📦 TypeScript monorepos: You have worked in a large TypeScript, Node.js or JavaScript monorepo.

 - ⚙️ Developer platforms: You have experience with GitHub Actions, Linear, test infrastructure, preview environments or internal developer platforms.

 - 🧑‍🤝‍🧑 Growing a team: You've mentored engineers or helped shape a new team as an initiative grew beyond one person.

 - 🌍 Open-source communities: You have contributed to open-source or source-available projects with active developer communities.

 - 🏢 B2B SaaS context: You understand environments where reliability, permissions, data handling and customer trust are central.

 - 🔗 Workflow automation: You're familiar with workflow automation, integration platforms, AI orchestration or developer-facing products.
